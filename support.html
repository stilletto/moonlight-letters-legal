Android player help

Player support

Practical help for installation, saves, audio, advertising and test feedback.

Before reporting a problem

  • Install the latest version available to your testing account.
  • Restart the app and confirm that Android has free storage space.
  • Check the in-game language, audio and accessibility settings.
  • For network-dependent ads, test again on a stable connection.

Save and progress issues

Moonlight Letters saves progress locally. Avoid clearing app storage unless you intend to remove saves. If progress appears missing, confirm that you are using the same Android user profile and have not reinstalled or cleared the app.

Purchases

The current Android test release does not enable real-money purchases. Never send payment-card details, passwords or a complete store receipt in a support request. If a future version enables Google Play products, this page will be updated with product-specific restore and refund guidance.

Delete local data

Moonlight Letters does not require a server account. To delete game data, open Android Settings → Apps → Moonlight Letters → Storage → Clear storage, or uninstall the app. This removes local saves, choices and settings from that device. If Android backup is enabled, also manage or delete the device backup through your Android and Google account settings to prevent later restoration.

Report a test issue

Include the app version, Android version, device model, selected language, the screen or chapter affected, and steps that reproduce the problem. Screenshots are useful when they do not contain private information.
